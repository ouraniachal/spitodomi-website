# Spitodomi Website 🏠

**Spitodomi Website** is a multi-page static website built with HTML, CSS, and JavaScript.  
It is designed to showcase services and projects in a clean and responsive layout, featuring modern styling and interactive effects.

## 🌟 Overview

**Spitodomi** provides specialized construction services with years of experience and a strong commitment to quality. Our website is designed to communicate professionalism and attract clients, offering an intuitive and visually appealing interface.

## 📖 Features
- **Multi-Page Layout** – Includes Home, Projects, and Services pages.
- **Responsive Design** – Optimized for desktop, tablet, and mobile devices using Flexbox/Grid.
- **Interactive Elements** – Custom JavaScript (`effects.js`) adds dynamic functionality and smooth user experiences.
- **Organized Assets** – Images and resources stored neatly in the `assets/` directory.
- **Clean & Semantic HTML5** – Structured and easy to maintain.

## 🛠️ Technologies Used
- **HTML5** – Semantic structure  
- **CSS3** – Styling with responsiveness and layouts
- **Bootstrap** – Responsive components
- **JavaScript (Vanilla)** – Interactivity via `effects.js`
